# Lessons

One line per miss: date, the class of miss, the mechanism that now catches it.

- 2026-09-17 — A function's early-return branch (library already present) had no test at all; three mutants in it survived the nightly for a week. Caught now by `tests/test_setup_cli.py` (both arms in one test); the class is caught by the nightly mutation job's Haiku triage naming the missing test per gap (`nightly-guardrails.yml`).
- 2026-09-17 — A pass-through function (server._render → render_ldraw) had 19 survivors: every test ran with the renderer disabled, so the call was never observed. Caught now by `tests/test_server_render_call.py` (a spy asserting every argument and the returned bytes). Class: when the real dependency is stubbed out, at least one test must assert the CALL, not just the result.
- 2026-09-17 — Three discovery functions (env → PATH → home → distro path) had 28 survivors: the disable switch that keeps CI off real Blender also kept every search branch unobserved. Caught now by `tests/test_render_discovery.py` (one test per branch; the literal distro path is reached by redirecting `render.Path`). Class: a kill switch that skips a subsystem in CI also skips its cheap, pure lookup logic — test those branches directly with the switch off.
- 2026-09-18 — PR review: `search_parts` cached its index on the `parts/` DIRECTORY's mtime, which an in-place rewrite of a part file does not change, so a long-lived server kept serving old descriptions; the same PR keyed the LDConfig cache correctly on the file itself. Caught now by `test_a_part_rewritten_in_place_is_searched_by_its_new_description` (pins the directory mtime, rewrites the file, seen to fail on the old key). Class: a cache key must be a property of the thing READ, not of its container; every cache gets one test that changes the source under a live cache.
- 2026-09-22 — Audit: a refusal allowlist named one member of an exception family (`FileNotFoundError`), so its siblings (`PermissionError`, `IsADirectoryError`, a Blender that cannot be exec'd, #41) stayed masked; the fuzz fix for #29 had wrapped one more call site instead of naming the family. Caught now by `test_the_whole_oserror_family_is_a_refusal_and_a_bug_is_not` plus one through-the-client test per sibling. Class: classify refusals by the family the caller can act on, never by the member that was last seen; a test asserts the family, beside a bug type that must stay masked.
- 2026-09-22 — Audit: numeric tool arguments went to Blender unchecked and Blender CLAMPS instead of refusing, so a nonsense request came back as a success (4x4 image); no upper bound meant timeouts instead of refusals. Caught now by `test_out_of_range_render_parameters_are_refused_before_blender` / `test_render_parameters_have_upper_bounds` (a subprocess spy proves Blender never started, edges prove it still does). Class: every numeric argument that crosses a process boundary gets explicit bounds at our side, and a real render asserts the output has the requested size.
